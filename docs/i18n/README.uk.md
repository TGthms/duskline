# Duskline

Безкоштовний погодний застосунок лише в браузері: пошук міст у всьому світі, погодинний і 10-денний огляд, якість повітря, анімовані умови та розширені прогнози й попередження U.S. National Weather Service.

[Відкрити duskline](https://dusklineweather.pages.dev/) · [Політика конфіденційності](../../privacy.html) · [Умови використання](../../terms.html)

Немає облікового запису, власного бекенду чи рекламного ідентифікатора. Мова, одиниці, обране та навмисно наближене збережене місцезнаходження лишаються в браузері.

## Можливості

- Шукайте будь-яке місто світу, з підказками зручними для клавіатури
- Зберігайте обране й за бажанням використовуйте місцезнаходження (координати округлюються перед збереженням або надсиланням)
- Поточні умови, погодинний прогноз і 10-денний огляд
- Якість повітря
- Для відповідних місць у США — прогнози й публічні попередження National Weather Service
- Анімоване небо й опади в докладному вигляді
- Одиниці температури, відстані, вітру, опадів і тиску
- 30 мов інтерфейсу, зокрема арабська та іврит (справа наліво)

## Конфіденційність і дані

Погодні запити виходять із браузера до [Open-Meteo](https://open-meteo.com/) і для місць у США — до [National Weather Service](https://www.weather.gov/). Якщо ви використовуєте місцезнаходження, зворотне геокодування йде до BigDataCloud і може перейти до OpenStreetMap Nominatim. Хостинг і Google Fonts можуть бачити звичайні технічні дані запиту.

duskline не продає цю інформацію. Прогнози потрібні для планування й дослідження, а не для екстрених рішень. Подробиці: [Політика конфіденційності](../../privacy.html) і [Умови використання](../../terms.html).

## Мови

Вибір мови в застосунку та юридичні сторінки використовують ті самі 30 локалей і налаштування `duskline-lang`. Юридичні тексти лежать у `src/js/data/legal/packs/`. Ці переклади README — у [`docs/i18n/`](README.md).

## Розробка

Застосунок — статичні HTML, CSS і класичні скрипти, без збирача.

```bash
npm run serve
# http://127.0.0.1:8000/
```

- Перевірка синтаксису кожного власного JS: `npm run check`
- Модульні тести: `npm run test:unit`
- Smoke Playwright підміняють погодні API й не витрачають живі квоти: `npm test`
