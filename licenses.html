Lucide icons

The selected Lucide SVG icons are embedded in the weather page’s inline sprite. This lets the symbols render when the page is opened directly from a local file as well as from a web server. Lucide is licensed under ISC; icons derived from Feather are also covered by the included MIT notice.

Read the complete Lucide license notice

MapLibre GL JS

The weather map lazily loads MapLibre GL JS 6.11.2 from the bundled local files. Its license file contains the MapLibre notice and notices for bundled dependencies.

Read the complete MapLibre and dependency notices

OpenFreeMap and OpenStreetMap

When you open the weather map, visible map tiles are provided by OpenFreeMap using OpenStreetMap data. The map displays attribution to OpenFreeMap and OpenStreetMap contributors.
